Trilhas de aprendizado

Programação do Zero

Comece sua jornada na programação sem precisar saber nada antes. Vamos do raciocínio lógico até a criação do seu primeiro site funcional. Você vai entender como o código funciona, por que ele importa e o que você pode construir com ele.

A oficina cobre lógica de programação, introdução ao HTML e CSS (a linguagem das páginas web) e os primeiros passos com JavaScript, a linguagem que faz os sites ganharem vida.

Lógica de Programação HTML CSS JavaScript Projetos práticos Do zero ao site
🤖

Robótica Criativa

A robótica não é só para engenheiros. Nessa oficina você vai colocar a mão na massa — literalmente — montando circuitos, programando microcontroladores e resolvendo desafios em equipe. É tecnologia que você pode ver e tocar.

Trabalharemos com conceitos de eletrônica básica, montagem de componentes, programação de hardware e resolução criativa de problemas. Cada participante sai com um projeto funcionando.

Eletrônica básica Montagem Programação de hardware Trabalho em equipe Criatividade
🌟

Carreira Tech

Conhecimento técnico é essencial, mas a carreira se constrói com muito mais. Nessa oficina você vai aprender a se apresentar ao mercado tech com confiança — seja para sua primeira vaga, uma transição de carreira ou uma promoção.

Abordamos construção de currículo para a área de tecnologia, LinkedIn estratégico, criação de portfólio online, dicas para processos seletivos e networking com profissionais da área.
